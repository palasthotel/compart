# Community participation (compart)

> [!WARNING]
> **This plugin is discontinued and the repository is archived.** It is no longer in
> use anywhere and receives no updates, fixes or security reviews.

WordPress plugin that let readers take part in content creation: visitors submitted
topic proposals through a form, the editorial team put proposals to a vote, and a
successful vote turned into a post. It brought a post type for votings, Gutenberg
blocks, a REST API and an admin menu.

The code is left as it was in 2021 (WordPress 5.8, GPL-2.0). Anyone who wants to build
on it should review it first, in particular the public proposal form.
